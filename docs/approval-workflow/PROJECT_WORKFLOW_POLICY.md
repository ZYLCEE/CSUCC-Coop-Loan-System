# CSUCC Cooperative Loan System — Project Workflow Specification v1.0

**Reference:** `docs/approval-workflow/PROJECT_WORKFLOW_POLICY.md`

This document records the workflow configuration used by this software project. It supports development and presentation using synthetic records; it is not a CSUCC board resolution or an institutional lending policy.

## Requirements review

- Staff review identity, eligibility and affordability, and the loan terms and payment projection.
- Required identity, payslip and applicable collateral documents must be submitted and verified.
- Borrower consent and co-maker consent are required for the configured workflow.
- The borrower submits the consent through the application's OTP-verified flow. Paper evidence is also enabled in the project configuration.
- Two witness names are recorded with the borrower's submission for this project workflow.

## Committee review

- CRECOM has three reviewers: two members and one chairperson. All three must approve.
- One BOD chairperson reviews every application after CRECOM.
- The Super Admin records the final decision after the required committee decisions, matching the activation function used by this project.
- All assigned reviewers must respond. A rejection blocks final approval.

## Use in this project

Use this file as the project workflow reference in the policy draft and activation settings. The workflow is implemented for synthetic project records and does not represent authority to issue or approve real loans.
